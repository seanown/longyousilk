## 1. 品牌定位一句話

**三方共創的絲綢藝術海報：廟方授權神明 IP，藝術家重新詮釋，廟方認可才發行，永不重印。**

拆成四個不可拆的要素：

| 要素 | 內容 | 為什麼不能拆 |
|---|---|---|
| 材質 | 萬事利（Wensli）絲綢，特別版用南京雲錦博物館等 | 價格的物質基礎 |
| 技術 | 日本防偽編號，隱藏於絲綢內部，特殊光照射才現形，每張編號不同 | 全世界沒人有的賣點 |
| IP | 88 間中華廟宇授權，歸入**南天門系列** | 別人跑不到的護城河 |
| 關卡 | **廟方認可**（兩階段送審） | 內容審查，非形式 |

**品牌宗旨**：推廣**中西融合共賞**的絲綢藝術展。
→ 具體機制：邀請**西方藝術家**重新詮釋中華神明，用西方人看得懂的視覺語言呈現。

**系列結構**：
- `Nantianmen Series` — 88 間中華廟宇 IP，主力
- `Global Icons` — Akira、The Godfather、Midnight Jazz 等世界文化題材，獨立系列
  （⚠️ 第三方 IP，與廟宇授權風險性質不同，故分開）

## 2. 設計原則（五條，衝突時以此裁決）

1. **網站是畫框，不是畫。** 任何裝飾若不能幫助作品被看見，就刪掉。
2. **稀缺性用事實陳述，不用催促。** 寫「Edition of 30」，不寫「只剩 3 張！」
3. **每一件作品都要看見三方署名。** 藝術家、廟方、絲廠——缺一就不是 SILKLY ART。
4. **中西融合要在視覺層面自己講出來。** 不靠文案解釋（詳見 §3 色彩）。
5. **零促銷語言。** 全站不出現 % OFF、倒數計時、限時、彈窗。

### 衝突裁決範例
- 「想加倒數計時增加轉換」→ 違反原則 2 與 5，否決。
- 「商品卡想加陰影立體感」→ 違反原則 1，否決。
- 「想用紅色標價吸引注意」→ 違反原則 4（朱紅是印章專用），否決。

## 3. 色彩系統（方案 B+：絹本 ＋ 近白）

### 3.1 為什麼是 B+

商業模式是「**中華 IP ＋ 西方藝術家詮釋**」。B+ 的配色結構與之**同構**：

- 絹本米白 ＝ 中華的內容與材質
- 高對比 serif 標題 ＝ 西方美術館語彙

→ **網站本身就是「中華內容 + 西方形式」，與作品一模一樣。**
客人還沒讀到任何一個字，光看版面材質與字體關係，就已經感受到宗旨。

**反觀落選的兩套**：
- A（白盒子 #FCFCFA）：中性無立場，白底＋serif 是每家限量版畫站都在用，客人不會記得你是誰。
- C（墨夜 #0E0E0D）：黑金是西方奢華語彙，中華材質感被壓過，**方向與宗旨相反**。

### 3.2 色票

| 代號 | 色值 | 用途 | 對比度（vs 底） |
|---|---|---|---|
| `ink` | `#1C1A16` | 所有文字、按鈕底 | 15.0:1（vs 絹本）／16.0:1（vs 近白） ✅ |
| `silk-paper` | `#F2EDE3` | **敘事區塊**底：Hero、The Craft、Temples 牆、Exhibitions | — |
| `silk-white` | `#F7F4ED` | **商品區**底：作品列表、商品頁、表單 | — |
| `seal` 印章朱 | `#9E2B25` | 🔴 **只做廟方認可標記**與裝飾，面積 <5% | 6.4:1 ✅ |
| `gold-deep` 絹金 | `#7A6740` | 需要金色的小字（年份、分隔、標籤） | 4.6:1 ✅（僅達 AA 門檻，勿用於長文） |
| `gold` 絹金亮 | `#A08A5B` | ⚠️ **僅限裝飾與大標題**，不可用於正文 | 2.8:1 ❌ |
| `mute` 次要灰 | `#6B6252` | 副標、meta、說明文字 | 5.9:1 ✅ |

### 3.3 🔴 兩條硬規則

**規則一：絹本 `#F2EDE3` 只用在敘事區塊，商品區一律回到 `#F7F4ED`。**
理由：全站米白會讓作品顯舊，尤其南天門系列的鮮豔紅金藍。
→ 分區同時創造節奏：讀故事（絹本）→ 看作品（近白）→ 讀故事（絹本）。

**規則二：印章朱 `#9E2B25` 不出現在價格上。**
理由：朱紅一用來標價就變成商業色；**只用在廟方認可，它才是印章**。
印章在中國畫的語意是「作者署名與真偽保證」——正好呼應日本防偽編號。
→ 印章朱的允許出現位置（全站僅這四處）：
1. 商品頁 `Approved by [廟名]` 的廟名標記
2. 分隔線／章形裝飾（裝裱感）
3. Primary 按鈕的 hover 態
4. 導覽項 hover 的底線

### 3.4 CSS 變數

```css
:root{
  --ink:#1C1A16; --mute:#6B6252;
  --silk-paper:#F2EDE3; --silk-white:#F7F4ED;
  --seal:#9E2B25; --gold:#A08A5B; --gold-deep:#7A6740;
  --line: rgba(28,26,22,.14);
  --radius:2px;                 /* 全站銳利，印刷品感，不用 8px 圓潤 */
  --space:8px;                  /* 8px 基準 */
  --measure:68ch;               /* 文字行寬上限 */
}
```

## 4. 字體系統

### 4.1 三種字體

| 角色 | 字體 | 說明 |
|---|---|---|
| 標題 Display | 高對比 serif | 付費：Canela／Tiempos Headline／Editorial New<br>免費替代：Playfair Display／Cormorant Garamond（**後兩者偏古典，需實測**） |
| 內文 Body | 中性 sans | Inter／Söhne／系統 sans（`system-ui, -apple-system, "Segoe UI"`） |
| 繁中漢字 | 思源宋體／思源黑體 | **Noto Serif TC**（標題）＋ **Noto Sans TC**（內文） |

### 4.2 🔴 字體載入的策略（重要）

網站英文為主，但廟宇名、神明名（哪吒、媽祖）會出現漢字。

- **不要用 Google Fonts CDN**。中國大陸訪客會載入失敗、拖慢首屏。
- 做法：字體檔案**自架**（放在 `/fonts/`，woff2 格式，`font-display:swap`）。
- 字體棧必須有系統 fallback，載入失敗時不能崩版：
  ```css
  --font-display: "Canela", "Playfair Display", "Noto Serif TC", Georgia, "Times New Roman", serif;
  --font-body: "Inter", "Noto Sans TC", system-ui, -apple-system, "Segoe UI", sans-serif;
  ```
- 漢字權重高（一個 Noto Serif TC 全字集 woff2 可達 8–15MB）→ **必須做子集化**（只保留網站會用到的字）或改用系統字體（macOS 的「Songti TC」、Windows 的「微軟正黑體」）。
  → 建議第一版：漢字**只用系統字體**，不做自架；先求穩定，第二版再優化。

### 4.3 級距（desktop，行動版 ×0.75）

| 層級 | 字體 | 大小／行高／字距 | 用途 |
|---|---|---|---|
| Hero h1 | serif | 56px / 1.1 / -0.02em | 首頁定位宣言 |
| Section h2 | serif | 34px / 1.2 / -0.01em | 區塊標題 |
| Work title h3 | serif | 20px / 1.3 / 0 | 作品名（卡片與商品頁） |
| Eyebrow | sans | 12px / 1.4 / **0.14em** / 大寫 | 小標籤（TEMPLE APPROVED、EDITION） |
| Body | sans | 16px / 1.7 / 0 | 內文，行寬 ≤68ch |
| Small | sans | 14px / 1.6 / 0 | 說明、表單 |
| Caption | sans | 13px / 1.5 / 0.02em | meta（尺寸、版數、年份） |

**字重只用兩級**：400（內文）與 500（標題）。不用 600／700。

## 5. 間距與網格

- **基準 8px**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`
- **容器**：`max-width: 1280px`，左右 padding 行動版 24px／桌機 48px
- **網格**：12 欄，gap 24px
- **區塊垂直節奏**：桌機 128px，行動版 72px（section 之間）
- **作品列表**：桌機 3 欄／平板 2 欄／手機 1 欄，gap 32px
- **商品圖比例**：3:4（海報直立比例），`object-fit: cover`

## 6. 元件規範

### 6.1 導覽
- 高度 72px，sticky，底色 `silk-white`，底部 1px `--line`
- 項目：`Works · Artists · Exhibitions · For Artists · About`
  （**Artists 在第一層**——Mondo 黃金期沒有藝術家頁，那是它最大的洞）
- hover：底線 1px `seal` 印章朱（這是朱紅四個允許位置之一）
- 手機：漢堡選單，全螢幕絹本底覆蓋

### 6.2 商品卡
- **無框線、無陰影**（原則 1）
- 圖 3:4 → 下方文字區：
  - 作品名 serif 18px `ink`
  - 藝術家 sans 13px `mute`
  - 版數 sans 13px `mute`（例：`Edition of 30`）
  - 價格 sans 15px **`ink`**（🔴 不用朱紅，見 §3.3 規則二）
- 售罄：整卡降至 60% 透明度，疊一行 sans 13px `mute` 的 `Sold out`（**不用紅色**）

### 6.3 按鈕
| 類型 | 樣式 |
|---|---|
| Primary | 實心 `ink` 底、白字、`radius:2px`、padding 14px 28px；hover 轉 `seal` |
| Secondary | 1px `ink` 邊框、透明底、`ink` 字；hover 底轉 `ink`、字轉白 |
| Text | 無邊框，`ink` 字 + 1px 底線；hover 底線轉 `seal` |

- 🔴 **全站圓角 2px**。不用 8px 圓潤——限量藝術品要印刷品的銳利感，不要 SaaS 的親切感。

### 6.4 徽章（Edition ／ Variant ／ Sold out）
- 1px `--line` 邊框的小標籤，透明底，sans 12px，字距 0.06em
- 🔴 **不用實心色塊**。實心色塊會立刻變成促銷貼紙（違反原則 5）

### 6.5 表單
- 輸入框：無外框，**只有 1px 底線**（`--line`）；聚焦時底線轉 `gold-deep`
- 標籤：Eyebrow 級（12px / 0.14em / 大寫）
- 送出：Primary 按鈕

## 7. 頁面規格

### 7.1 首頁（六區塊，底色交替）

| # | 區塊 | 底色 | 內容 |
|---|---|---|---|
| 1 | Hero | 絹本 | 一張大作品圖 ＋ 定位宣言 ＋ 藝術家名。高度 100vh（行動版 auto） |
| 2 | **The Craft** | 絹本 | 三張照片時間軸，**步驟當標題**（見 §7.2） |
| 3 | Featured Works | 近白 | 精選 **6 件**，3×2 網格 |
| 4 | **88 Temples 牆** | 絹本 | `88 TEMPLES · ONE SILK CANVAS`，88 個廟名高密度排列，點進 Temples 總覽 |
| 5 | Exhibitions | 絹本 | 當前／即將檔期：城市、場地、日期 |
| 6 | Collector's List | 近白 | 一行 email 訂閱 ＋ 一句話 |

**區塊順序的邏輯**：先讓客人看見作品有多好（3），再告訴他憑什麼（4），最後給行動（6）。
Mondo 2011 首頁只有 2 張純圖片橫幅；我們補上形象區塊，但仍維持極簡——**6 區塊 vs Displate 的 10 區塊**。

### 7.2 The Craft（品牌故事主線，工藝為主角不是人）

三張照片，主角是**手**不是臉：
1. 蠶繭到生絲 — 6A 級桑蠶絲產地
2. 織造 — 22 姆米、幾色緯線怎麼織出來
3. 手繡與裝裱 — 繡坊師傅的手

每段 60–90 字。**🔴 這是品牌形象主力，也是給藝術家看的招募文案**（「你的作品會被這樣對待」）。

### 7.3 商品頁（欄位順序，照 Mondo 2013 公告格式 ＋ 廟方認可）

```
[作品大圖]  [細節圖]  [防偽對照圖：正常光 vs 紫外光]

作品名                          ← serif h3
by 藝術家名                      ← 可點進藝術家頁

策展敘事句（60–120 字）          ← 講這件作品為什麼存在，不是講規格

────────────────────────
✓ Approved by 鹿港天后宮, 2026   ← 🔴 印章朱標記。全頁最重要的一行
────────────────────────

Silk by Wensli                  ← 或 Mill: Nanjing Yunjin Museum（每版具名）
22 momme · N-colour weft
尺寸：70 × 100 cm
Edition of 30
Signed and numbered by the artist
Hidden registration no.（unique per piece）

價格                              ← ink，不用朱紅
Never to be reissued              ← 🔴 照抄 Mondo 承諾，二級溢價的真正來源

[Add to cart]  [Join Collector's List]
```

**`Approved by` 這一行的規格**（軒哥拍板 1+3 漸進式）：
- **底線**：每件都寫 `Approved by [廟名], [年份]`
- **加分**：談到書面同意的廟，加放認可書影像
- 先做幾間示範，**不等 88 間全談完才上線**；先談成的可當說服後面廟方的樣本

### 7.4 Artists 頁（導覽第一層）

- 藝術家網格：縮圖 ＋ 姓名 ＋ 城市／國籍 ＋ 作品數
- 藝術家專頁：簡介、作品列表、**Artist Wishlist**（他最想重新詮釋哪一位中華神明）
- 🔴 這是 Mondo 的洞，也是招募的落地點

### 7.5 For Artists 頁（🔴 招募主戰場）

**標題方向**：`Reimagine a deity.`（不是「Sell your art with us」）

**核心命題**：從「招供應商」改成「**命題創作**」。藝術家愛命題。

**Artist Wishlist 的問題**（照 Mondo 的配對法改造）：
> Mondo 問：「你最想畫的十部片是什麼？」
> 我們問：「**你最想重新詮釋哪一位中華神明？為什麼？**」
> → 這題本身就是最好的篩選器：答得出來的人，就是我們要的人。

**流程必須完整公開**（六步）：
1. 提交作品集 ＋ 回答上述問題
2. 我們配對廟宇與神明
3. **草圖送廟方**（2–3 週回覆）
4. 廟方認可後才畫正式版
5. 絲綢打樣、防偽編號、藝術家簽名
6. 發行 → 展覽 → 分潤

**認可標準要寫輪廓，不能是黑箱**（講精神，不寫死規則）：
- 廟方在看：神明的可辨識度、莊嚴感、有無違和元素
- 退件時：給一次明確修改方向，**不是直接作廢**

🔴 **為什麼一定要兩階段送審**（軒哥已拍板）：
一個法國藝術家花三週畫哪吒，畫完才送審被退，他不會覺得是文化差異，他會覺得**被耍了**。
西方藝術圈很小，這種事傳很快。草圖先送同時降低兩件事——藝術家的沉沒成本，廟方的否決率
（看草圖說「帽子不對」很容易改；看成品說「整體不對」就沒救）。
**而這套流程寫在招募頁上，本身就是最好的文案**——證明你懂藝術家在怕什麼。

**分潤**：公開階級名，不公開數字。

### 7.6 Temples 頁（廟宇牆 ＋ 總覽）

- **首頁牆**：`88 TEMPLES · ONE SILK CANVAS`，88 個廟名高密度排列（sans 13px，`gold-deep` 或 `mute`）
  → 對應 Displate 的 200+ FANDOMS 牆，但我們的是真授權
- **Temples 總覽頁**：四欄表格 — 名稱（中英）／縣市／年代／主祀神明
- **篩選維度**：按神明篩（哪吒、媽祖、關帝…）
  → 「同一尊神 × 不同藝術家」並列，是 Mondo 給不起的內容
  （Mondo 的 IP 是片廠的死 IP；我們的 IP 是活的——真有人在拜，廟方真的會看畫說「這不是我家的神」）

### 7.7 Exhibitions

- 當前／即將／過往三區
- 每檔：城市、場地、日期、展出作品
- 🔴 **Mondo 實體畫廊已停擺 6 年**（網站仍寫「Due to COVID-19... currently closed」，
  最後一檔停在 2020/3 GODZILLA）。我們有活的展覽，這是**明確的超車位**，要放大。

### 7.8 About

1. **The Craft**（主，佔 60%）：三段工藝，同 §7.2
2. **品牌宗旨**（20%）：中西融合共賞
3. **創辦人故事**（次，20%，放後段）：可放但**不搶 The Craft**
   → 愛馬仕講皮革、百達翡麗講機芯，**沒有一家奢侈品靠創辦人自述撐起來**

## 8. 文案語氣規範

### 8.1 要做
- 檔案式陳述：`Edition of 30. Signed and numbered. Never to be reissued.`
- 用具名：`Silk by Wensli`、`Approved by 鹿港天后宮`、`captured here by [artist]`
- 現在式、短句、具體數字
- 美術館展籤語氣（「captured here by X」），不是募捐語氣（「Every purchase supports an artist」）

### 8.2 不要做（寫進 lint 檢查）
| 禁止 | 原因 |
|---|---|
| `% OFF`、`限時`、`最後機會`、`馬上搶` | 違反原則 5，破壞奢侈品感 |
| 倒數計時器 | 高涉入決策（USD 890+）用倒數只會損失訂單 |
| 首頁彈窗 | 違反原則 1 |
| 驚嘆號 | 語氣不對 |
| `投資`、`增值`、`保值`、`收藏首選` | 🔴 版數 8–50 張不存在二手市場，說了是欺騙 |
| 假稀缺（「只剩 3 張」但補貨） | 一次被抓到，品牌就完了 |
