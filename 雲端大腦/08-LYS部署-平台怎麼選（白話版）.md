## 一、為什麼 LYS 不能跟另外兩個站一樣放 Netlify？

你另外兩個站（seanown.org、ownsean.com）是**純展示網站**——
就是把做好的檔案放上去，有人來就傳給他看。像傳單。Netlify 免費又穩，很適合。

**LYS 不一樣**，它有「後台」（可以登入改作品、改展覽）。
後台需要一支程式（`server.js`）**一直在跑**，像便利商店要有店員顧著，
不能只放傳單在門口。

Netlify 只放傳單，**不提供店員**。所以 LYS 要另外找地方。

Render 和 Railway 就是「幫你顧店」的地方：它們租一台雲端電腦給你，24 小時幫你跑 `server.js`。

---

## 二、「休眠」是什麼？

雲端那台電腦為了省電，**15 分鐘沒人來就自動關機**。
下次有人來，它才重新開機——**要等約 1 分鐘**。

```
有人來 → 網站正常開（秒開）
   ↓ 15 分鐘都沒人來
自動關機（休眠）
   ↓ 有人再來
重新開機中...等約 1 分鐘
   ↓
網站又活了（之後又恢復秒開）
```

**實際影響**：如果一天只有幾個人來看 LYS，
那這幾個人第一次點開時可能要等 1 分鐘。就這樣，沒有別的壞處。

## 三、Render vs Railway（2026-09-04 查證）

| | **Render 免費** | **Railway 免費** |
|---|---|---|
| 每個月給你 | **750 小時**（一個月才 730 小時，等於可以整月開著） | **$1 美元額度** |
| 會不會休眠 | 會，15 分鐘沒人來就關機，下次等約 1 分鐘 | **額度花完直接停站，要等到下個月** |
| 實際能用多久 | 整個月都在（只是要等開機） | **$1 大概幾天就花完**，花完網站就關了 |
| 需要信用卡 | 不用 | 不用 |
| 付費方案 | $7/月（不休眠、秒開） | $5/月（Hobby） |

### ⚠️ 關鍵結論

**免費的話，Render 明顯贏。**

Railway 的免費額度只有 $1/月，扣完就關站，
一個月大部分時間網站是死的——比 Render 的「等 1 分鐘」嚴重得多。
Railway 要實用得買 $5/月方案。

## 四、我的建議

**先用 Render 免費。**

理由：
1. LYS 現在還沒有客人流量，「第一次點開等 1 分鐘」根本不是問題
2. 完全不用錢、不用信用卡
3. 等真的有客人、覺得等待礙事了，再升級 $7/月，一鍵的事

**什麼時候該升級 $7/月**：開始有客人要看作品、或你要拿這個網址去給人報價的時候。

---

## 五、⚠️ 一個重要的坑（一定要知道）

Render 免費方案的硬碟是**暫存的**——
你在「線上後台」改的資料（新增作品、改價格），
**只要網站休眠或重新部署，就會全部不見。**

### 解法（建議的工作流程）

```
在本機開後台改資料
   ↓ 改完
跟我說一聲，我幫你 commit + push 到 GitHub
   ↓
Render 自動重新部署，線上就更新了
```

**白話講：後台只在你自己電腦用，線上那個站是「展示版」。**
這樣資料永遠不會丟，而且每次改都有版本記錄。

（備註：其實這也是比較專業的做法，很多公司都這樣跑。）

## 六、要動手時，你只需要做這些

1. 開 https://render.com → 用 **GitHub 帳號**登入
2. 按 **New +** → 選 **Web Service**
3. 選 `seanown/longyousilk` 這個 repo
4. 設定它會自動帶入（`render.yaml` 我已經寫好了），直接按 **Deploy**
5. 等約 2 分鐘，它會給你一個網址，像 `https://lys-longyousilk.onrender.com`

**上線前還有兩件事要做**（見待辦清單）：
- 改後台密碼（現在 `lys2026`，全世界都看得到）
- 決定要不要綁你自己的網址
