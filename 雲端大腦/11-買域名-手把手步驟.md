## 二、購買步驟（約 5 分鐘）

### 步驟 1：登入並搜尋
1. 開 https://www.name.com/ → 右上角 **Log In**
2. 登入後，頁面中間的搜尋框輸入 `longyousilk.com`
3. 按 **Search**（放大鏡圖示）

### 步驟 2：加入購物車
1. 結果頁會出現 **longyousilk.com — Available**，右邊有價格
2. 按 **Add to cart**（不是 "Make offer"，我們是買全新未註冊的域名）
3. 如果出現其他後綴推薦（.net / .org / .co 等），**不用勾**

### 步驟 3：結帳（關鍵）
1. 右上角購物車圖示 → **Checkout**
2. ⚠️ **結帳頁會出現加購，全部不要勾**：
   - ❌ Email hosting（我們用 Gmail）
   - ❌ Web hosting（網站跑在 Render）
   - ❌ SSL certificate（Render 免費送）
   - ❌ Website builder（不需要）
3. ✅ **Domain Privacy（WHOIS 隱私）一定要選** —— name.com 有免費版本，選 **FREE** 那個
   （它有時會推付費的 "Premium Privacy"，不用買，免費版就夠保護個資）
4. 勾選 **Auto-renew**（自動續約，避免忘記繳費域名被撿走）
5. 付款 → 完成

## 三、買好之後：綁到 Render

### 步驟 4：在 Render 加自訂域名
1. 開 https://dashboard.render.com/
2. 點服務 **longyousilk**
3. 左邊選單 **Settings** → 往下找 **Custom Domains**
4. 按 **Add Custom Domain**，輸入 `longyousilk.com` → Save
5. Render 會顯示需要你加的 DNS 記錄，通常長這樣：

| 要綁的網址 | 記錄類型 | 內容 |
|---|---|---|
| `www.longyousilk.com` | **CNAME** | `longyousilk.onrender.com` |
| `longyousilk.com`（根網址） | **A** 或 **ALIAS** | Render 會給一組 IP 或主機名稱 |

> **實際內容以 Render 畫面顯示為準，照抄即可。**

### 步驟 5：到 name.com 加 DNS 記錄
1. 回 name.com → 右上角帳號 → **My Domains**
2. 點 `longyousilk.com`
3. 選 **DNS Records** 分頁（或 "Manage DNS"）
4. 按 **Add Record**
5. 依 Render 給的內容填入（name.com 欄位名稱通常是 **Type / Host / Answer / TTL**，
   別家可能叫 Name / Value，意思一樣）：
   - **Type**：CNAME
   - **Host**：`www`
   - **Answer**：`longyousilk.onrender.com`
   - **TTL**：用預設值（通常是 300）
6. 根網址那條也照 Render 指示加（A 記錄就填它給的 IP）
7. 儲存

### 步驟 6：等生效
- 通常 **5–30 分鐘**，最慢 24 小時
- Render 會自動申請 **免費 SSL 憑證**（網址列出現鎖頭 🔒）
- 生效後開 https://longyousilk.com 就會看到 LYS 網站

## 四之二、兩個品牌站關閉 WHOIS 隱私（2026-09-05 軒哥拍板）

**軒哥的決定（已確認）**：`seanown.org` **和** `ownsean.com` **兩個都公開**。

這個決定是對的 —— 企業客戶、媒體、合作方要確認網域所有權時會查 WHOIS，
藏起來反而像是「不敢見人」。個人品牌要的就是能被找到，而且兩個品牌站一致，
中英文客戶查到的都是同一個人，形象才完整。

### 🔴 第一步（最重要）：先把要公開的資料改成對的

**順序不能反！先改資料，再關隱私。** 如果先關、資料還是舊的住家地址，
那就會被公開出去，事後改還要再等一次生效。

> 介面路徑已按 2026-09-05 軒哥實際截圖確認 ✅：
> 域名詳情頁左欄有兩個區塊——**Quick Actions**（放 WHOIS Privacy 開關）、
> **Domain Actions**（放 Manage Contacts 改資料入口）。

1. 登入 https://www.name.com/
2. 右上角帳號 → **My Domains** → 點 **`seanown.org`** 進入域名詳情頁
3. 左欄 **Domain Actions** 區塊 → 點 **Manage Contacts**
4. 逐項檢查並改成下面這張表：

| 欄位 | 建議內容 | 注意 |
|---|---|---|
| Name / Organization | `Sean Own` | 品牌露出，加分，照實填 |
| Email | `seanown@gmail.com` | 和網站上的聯絡信箱一致，客戶查得到 |
| Phone | **工作用手機** | ❌ 不要填私人號碼 |
| Address | **公司地址或 PO Box** | ❌ 千萬不要填住家地址 |

5. 儲存後，**`ownsean.com` 重複同一套動作**（兩個域名填一樣的資料，形象一致）
6. 改完先等約 15 分鐘讓資料同步

### 第二步：關閉隱私（兩個域名都要做）

對 **`seanown.org`** 做一次，再對 **`ownsean.com`** 做一次：

1. name.com → **My Domains** → 點該網域名稱進詳情頁
2. 左欄 **Quick Actions** 區塊找到 **WHOIS Privacy** 開關
3. 把開關撥到 **OFF**（OFF = 公開、ON = 藏起來 —— 跟直覺相反，別撥錯方向）
4. **最多 15 分鐘**後生效（官方說明：up to 15 minutes）

> ⚠️ 開關方向是最大陷阱：**OFF = 公開，ON = 隱藏**。
> 2026-09-05 截圖確認：`silklyart.com` 的 WHOIS Privacy 顯示 OFF，
> 意思是它的資料**正在公開中**——電商域名恰恰需要撥回 ON 保護。

> 補充：name.com 現在把隱私服務包在 **Domain Safe** 產品裡
> （免費版含 privacy + SSL + security locks，付費版叫 Domain Safe Pro）。
> 如果介面上看到的是 "Domain Safe" 而不是 "Whois Privacy"，點它進去關隱私即可。

### 第三步：驗收（30 分鐘後再查）

開這兩個網址，應該要看到你自己的名字／組織，而不是 "Privacy Protect" 或註冊商的代管資訊：

- https://who.is/whois/seanown.org
- https://who.is/whois/ownsean.com

> 如果 30 分鐘後還是顯示隱私資料，回 name.com 確認開關真的在 off，
> 或開無痕視窗重查（who.is 有時會快取舊結果）。

## 附：域名可註冊查核方式（可複用）

用 Verisign 官方 RDAP，HTTP 404 = 可註冊：

```
https://rdap.verisign.com/com/v1/domain/{要查的域名}
```

**一定要加對照組**再採信結果：
- `google.com` 應回傳 200（已註冊）
- 亂數網址（如 `zzqx-not-a-real-name-8842.com`）應回傳 404（可註冊）

兩組都對，才相信目標域名的判定結果。
（教訓：早期用 nslookup 查，曾被 DNS 伺服器回傳的 IP 誤導，以為域名已被註冊。）

查註冊商也可以用同一個 RDAP，看 `entities` 裡 `roles` 含 `registrar` 的 `fn` 欄位。
