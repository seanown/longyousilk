## 三、買好之後：綁到 Render（你要做的部分）

### 步驟 4：在 Render 加自訂域名
1. 開 https://dashboard.render.com/
2. 點服務 **longyousilk**
3. 左邊選單 **Settings** → 往下找 **Custom Domains**
4. 按 **Add Custom Domain**，輸入 `longyousilk.com`，按 Save
5. Render 會顯示一條要你加的 DNS 記錄，長這樣：

```
類型：CNAME
名稱：www
內容：longyousilk.onrender.com
```
（實際內容以 Render 畫面顯示為準，照抄即可）

### 步驟 5：到 Porkbun 加 DNS 記錄
1. 回 Porkbun → 右上角 **Account** → **Domain Management**
2. 點 `longyousilk.com` → **DNS Records**
3. 按 **Add Record**，把步驟 4 那條記錄貼進去
4. 儲存

### 步驟 6：等生效
- 通常 **5–30 分鐘**生效，最慢 24 小時
- Render 會自動幫你申請 **免費 SSL 憑證**（網址列出現鎖頭 🔒）
- 生效後開 https://longyousilk.com 就會看到 LYS 網站

## 四、常見問題

**Q：要不要連 `www.longyousilk.com` 一起設定？**
A：要。Render 會提示你加兩條（一條給 `longyousilk.com`、一條給 `www`），照做即可。
設定好後不管客人打哪個網址都會到同一個站。

**Q：要不要順便買 `longyousilk.art`？**
A：可買可不買。`.art` 對藝術品網站有識別度（約 $10-15/年），
但建議先把 `.com` 買好、網站跑順了再說。品牌保護是次要的，先把生意跑起來。

**Q：域名買下去就永久是我的嗎？**
A：是「租」的，每年要續約。到期沒續會被別人撿走。
**建議開啟自動續約（Auto-renew）**，並在行事曆記下到期日。

**Q：買了之後我的個資會不會被公開？**
A：不會。WHOIS Privacy 會把你的姓名、電話、地址遮蔽起來，這是免費的，一定要開。
