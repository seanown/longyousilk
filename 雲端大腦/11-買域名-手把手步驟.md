## 二、購買步驟（約 5 分鐘）

### 步驟 1：登入並搜尋
1. 開 https://www.name.com/ → 右上角 **Log In**
2. 登入後，頁面中間的搜尋框輸入 `longyousilk.com`
3. 按 **Search**（放大鏡圖示）

### 步驟 2：加入購物車
1. 結果頁會出現 **longyousilk.com — Available**，右邊有價格
2. 按 **Add to cart**（不是 "Make offer"，我們是買全新未註冊的域名）
3. 如果出現其他後綴推薦（.net / .org / .co 等），**不用勾**

### 步驟 3：結帳（關鍵）
1. 右上角購物車圖示 → **Checkout**
2. ⚠️ **結帳頁會出現加購，全部不要勾**：
   - ❌ Email hosting（我們用 Gmail）
   - ❌ Web hosting（網站跑在 Render）
   - ❌ SSL certificate（Render 免費送）
   - ❌ Website builder（不需要）
3. ✅ **Domain Privacy（WHOIS 隱私）一定要選** —— name.com 有免費版本，選 **FREE** 那個
   （它有時會推付費的 "Premium Privacy"，不用買，免費版就夠保護個資）
4. 勾選 **Auto-renew**（自動續約，避免忘記繳費域名被撿走）
5. 付款 → 完成

## 三、買好之後：綁到 Render

### 步驟 4：在 Render 加自訂域名
1. 開 https://dashboard.render.com/
2. 點服務 **longyousilk**
3. 左邊選單 **Settings** → 往下找 **Custom Domains**
4. 按 **Add Custom Domain**，輸入 `longyousilk.com` → Save
5. Render 會顯示需要你加的 DNS 記錄，通常長這樣：

| 要綁的網址 | 記錄類型 | 內容 |
|---|---|---|
| `www.longyousilk.com` | **CNAME** | `longyousilk.onrender.com` |
| `longyousilk.com`（根網址） | **A** 或 **ALIAS** | Render 會給一組 IP 或主機名稱 |

> **實際內容以 Render 畫面顯示為準，照抄即可。**

### 步驟 5：到 name.com 加 DNS 記錄
1. 回 name.com → 右上角帳號 → **My Domains**
2. 點 `longyousilk.com`
3. 選 **DNS Records** 分頁（或 "Manage DNS"）
4. 按 **Add Record**
5. 依 Render 給的內容填入（name.com 欄位名稱通常是 **Type / Host / Answer / TTL**，
   別家可能叫 Name / Value，意思一樣）：
   - **Type**：CNAME
   - **Host**：`www`
   - **Answer**：`longyousilk.onrender.com`
   - **TTL**：用預設值（通常是 300）
6. 根網址那條也照 Render 指示加（A 記錄就填它給的 IP）
7. 儲存

### 步驟 6：等生效
- 通常 **5–30 分鐘**，最慢 24 小時
- Render 會自動申請 **免費 SSL 憑證**（網址列出現鎖頭 🔒）
- 生效後開 https://longyousilk.com 就會看到 LYS 網站

A：可以，但目前不需要。網站跑在 Render，DNS 留在 name.com 就好。

## 四之二、seanown.org 關閉 WHOIS 隱私（2026-09-05 軒哥要求）

**軒哥的決定**：`seanown.org` 是個人品牌站，**不要開隱私保護，要讓人查得到**。

這個決定是對的 —— 企業客戶、媒體、合作方要確認網域所有權時會查 WHOIS，
藏起來反而像是「不敢見人」。個人品牌要的就是能被找到。

### name.com 官方關閉步驟

1. 登入 https://www.name.com/
2. 右上角按 **MY DOMAINS**
3. 點網域名稱 **`seanown.org`**
4. 左側 **Quick Actions** 區塊找到 **Whois Privacy**
5. 把開關 **toggle 到 off**
6. **最多 15 分鐘**後生效（官方說明：up to 15 minutes）

> 補充：name.com 現在把隱私服務包在 **Domain Safe** 產品裡
> （免費版含 privacy + SSL + security locks，付費版叫 Domain Safe Pro）。
> 如果介面上看到的是 "Domain Safe" 而不是 "Whois Privacy"，點它進去關隱私即可。

### 關閉後會公開什麼

| 欄位 | 會公開 | 建議填什麼 |
|---|---|---|
| 姓名 / 組織 | ✅ | `Sean Own` 或公司名（品牌露出，加分） |
| Email | ✅ | 建議用 `seanown@gmail.com`（品牌一致，客戶查得到） |
| 電話 | ✅ | 建議填工作用手機，不要用私人號 |

## 附：域名可註冊查核方式（可複用）

用 Verisign 官方 RDAP，HTTP 404 = 可註冊：

```
https://rdap.verisign.com/com/v1/domain/{要查的域名}
```

**一定要加對照組**再採信結果：
- `google.com` 應回傳 200（已註冊）
- 亂數網址（如 `zzqx-not-a-real-name-8842.com`）應回傳 404（可註冊）

兩組都對，才相信目標域名的判定結果。
（教訓：早期用 nslookup 查，曾被 DNS 伺服器回傳的 IP 誤導，以為域名已被註冊。）

查註冊商也可以用同一個 RDAP，看 `entities` 裡 `roles` 含 `registrar` 的 `fn` 欄位。
