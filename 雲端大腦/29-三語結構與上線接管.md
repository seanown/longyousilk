## 三、剩餘上線步驟（全由軒哥在 GUI 點，AI 不能代點）

1. **開 GitHub Pages**：
   - 開 `github.com/seanown/Silklyart` → Settings → Pages
   - Source = **Deploy from a branch** → Branch = **main** / 資料夾 **/(root)** → Save
   - 等 30 秒～2 分鐘，出現 `https://seanown.github.io/Silklyart/`（臨時網址，驗證用）
2. **綁 name.com DNS**（網域已買、WHOIS Private）：
   - 登入 name.com → 點 `silklyart.com` → DNS Records
   - 刪掉預設停放紀錄；新增 4 筆 **A 紀錄**（Host `@`）：
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - （選配）`www` → CNAME → `seanown.github.io`
   - DNS 生效 5 分～24 小時（通常 10–30 分）；`nslookup silklyart.com` 查。
3. **Enforce HTTPS**（DNS 生效後）：
   - 回 Pages 設定，Custom domain 自動帶出 `silklyart.com`（CNAME 檔已在）
   - 勾 **Enforce HTTPS**（GitHub 自動發 Let's Encrypt，約 5 分）
