## 五、雲端分工（東西該放哪）

| 放什麼 | 放哪 | 為什麼 |
|---|---|---|
| 程式碼、網站檔案 | **GitHub** | 版本控制，隨時 clone 到任何設備 |
| 知識、文章、風格提示詞、報告 | **IMA 知識庫** | 可以語意搜尋，AI 直接引用 |
| 照片、大檔案、影片 | **百度網盤** | 容量大 |
| 結構化清單、看板、日常工作台 | **Notion** | 手機最好看 |

### ⚠️ 各雲端的實際限制（2026-09-04 實測，很重要）

| 服務 | 能做 | 不能做 |
|---|---|---|
| **GitHub（MCP 連線）** | 讀取檔案、看 commit、搜尋 | ❌ **無寫入權限**（403）— 建 repo、建分支、改檔全部不行 |
| **GitHub（本機 git 命令列）** | ✅ **有推送權限**（實測 dry-run 認證成功） | 無法「新建」遠端 repo（要軒哥去網頁建） |
| **百度網盤（MCP）** | 上傳**純文字**（上限 2 萬字） | ❌ 不能傳圖片/二進位、單檔超過 2 萬字會失敗 |
| **IMA 知識庫** | 上傳文字類檔案（md/txt/pdf/docx），可語意搜尋 | 上限未知，但 90KB 的 md 實測可傳 |

**實務結論**：
- 知識類（文章、報告、風格檔）→ 交給 **IMA**，AI 自己就能傳完
- 程式碼 → 必須走 **GitHub**，但**遠端 repo 要軒哥手動建**（30 秒），建好後 AI 用本機 git 推
- 照片等二進位 → 走 **GitHub**（同上的 repo）或軒哥用百度網盤桌面版手動同步
