# 22 ｜ SILKY ART IP 用詞定稿：南天門

> 日期：2026-09-06（下午場）｜ 狀態：已落實公開網站

## 術語演變（三階）
1. 原：廟宇（宗教機構感，軒哥不要）
2. 過渡：民間信仰神祇（仍含「信仰」二字，軒哥不要）
3. **定稿：南天門**（中性、詩意、品牌化；完全無「廟宇／信仰」二字）

## 決策
- 中華神祇／民間信仰類 IP 的大傘名稱 = **南天門**（繁體「南天門」）。
- 三大 IP 支柱定稿：**南天門 ＋ 故宮文化 ＋ 敦煌**。
- works.html 保留「**南天門系列**」作為該支柱下的具體系列名（hero collection / 系列 的層級關係）。
- 描述文字統一用「**中華神祇與神話形象**（如媽祖、哪吒）」，不寫廟宇、不寫信仰。

## 軒哥原話
「信仰我們當然不這樣直接講，我直接把它寫南天門好嗎？南天門。」

## 我的評估（已回報，挺此決定）
- 南天門比「民間信仰神祇」更好：避開「信仰／廟宇」二字、已具品牌資產（works 本就叫南天門系列）、像收藏系列名而非分類標籤。
- 一盆冷水：南天門本義偏天界神話，若 IP 含媽祖（海神／地域性）稍窄；但作為品牌詩意命名完全 OK，描述文字「中華神祇與神話形象」已補寬。
